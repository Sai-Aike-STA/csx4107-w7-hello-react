Node.js is a JavaScript runtime environment that allows developers to
execute JavaScript code outside of a web browser, primarily on the
server-side.

It enables the creation of scalable and high-performance network
applications, including web servers, APIs, and real-time applications.
Node.js uses an event-driven, non-blocking I/O model, which makes it
efficient for handling concurrent requests.

# NVM (Node Version Manager)

Instead of installing Node JS directly, using Node Version Manager is a
good way to manage Node JS since it can help developers to select
current Node JS they would like to execute.

## Installing NVM on MacOS

NVM is available on Git Hub at <https://github.com/nvm-sh/nvm>

The following is a guide to install or update NVM but it may change time
to time, so you may check the latest document at the given link.

To install or update NVM, it requires "curl" or "wget", so please ensure
you can run curl or wget from your shell.

By default, CURL is preinstalled on MacOS, however, you can use homebrew
to update it as:

|                   |
|-------------------|
| brew install curl |

When CURL is ready, you can install NVM as:

|  |
|----|
| curl -o- <https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh> \| bash |

After running the install.sh, execute the following to add it's binary
into your path:

## Installing NVM on Windows

To run NVM on Windows, you can download the binary file at:
<https://github.com/coreybutler/nvm-windows/releases>

Run the installer:

- Set NVM installation path (default OK)
- Set Node.js installation path (default OK)

After installation, restart your terminal (PowerShell or CMD)

### Testing

You may testing if nvm had been installed successfully with the
following command:

|             |
|-------------|

## Install Node JS

Install specific Node JS version with NVM using:

nvm install

For example:

|                     |
|---------------------|
| nvm install 22.19.0 |

Note that the latest version is 24.11.1

## Listing installed version

You can list Node JS versions that installed on your system using:

|        |
|--------|
| nvm ls |

For example:

The one with "\*" is the active version.

This is useful when you have to work with several projects which may
running on different Node versions.
