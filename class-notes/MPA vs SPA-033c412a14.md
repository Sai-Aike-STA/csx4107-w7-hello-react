
## MPA — Multi-Page Application

Every time you click a link or button, the browser loads a new page from
the server.

### How it works:

- Each page = a separate HTML file
- Browser reloads the entire screen on navigation
- Backend decides what page to show

### Examples:

- Old websites
- Online newspapers
- E-commerce product pages
- Classic PHP websites

### Pros:

- Good for SEO
- Easy to build
- Each page loads fresh

### Cons:

- Slow navigation
- Full page reload every time
- More server work

## SPA — Single-Page Application

Only one HTML file is loaded, and the page updates using JavaScript
without reloading.

### How it works:

- Loads index.html once
- JavaScript updates the page content
- Navigation feels fast like an app
- React, Vue, Angular all build SPAs

### Examples:

- Gmail
- Facebook
- Twitter
- Any modern dashboard or web app

### Pros:

- Very fast navigation
- Better user experience
- Behaves like a mobile app

### Cons:

- SEO is harder
- Needs more JavaScript
- Initial load is slightly larger
