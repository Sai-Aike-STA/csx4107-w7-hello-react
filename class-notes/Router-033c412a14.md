for the application.

However, it is still be a SPA application, not MPA, the path is virtual
path and be interpreted with JavaScript not the web server.

## Hash Router

One problem about BrowerRouter is it does not work on Git Hub static web
service since Git Hub determine the "/" as actual sub folder from the
root folder.

If routing is required for Github static web service, we need to use
"HashRouter"

Simply change the BrowserRouter to HashRouter and re-deploy!

However, the path reference must be re-route to "#".

For example:

Normal path:
"<https://pop2518hotmailcom.github.io/hello-react-deploy/profile/123>"

Hash path:
"<https://pop2518hotmailcom.github.io/hello-react-deploy/#/profile/123>"

## Dynamic Path

In some case, we want to create a path ending with parameters, for
example:

/profile/123

When "123" is user id which is dynamic data consider as parameter.

We can implement with React Router simply as in the example:

}/\>

}/\>

In this example, our web application support both:

/profile and

/profile/:id for example, /profile/123

To get parameters in the component, simply get them with "useParams()"
function, for example

import { useParams } from "react-router-dom"

export function Profile () {

  const {id} = useParams();

  return (

    (!id) ?

<div>

Please specify ID...

</div>

 :

<div>

Profile: {id}

</div>

  )

}

In this example, we tried to get "id" as a path parameter with useParams
function, and then print data based on the existing of the id value.
This example demonstrates how to handle parameters.

## Query String

The query string is a strings in pattern of "key=value" start with "?"
character and separate each pair with "&".

For example:

<http://example.com/item?category=grocery&page=1&pagesize=10>

In React, we can get the query string using useSearchParams function.

import { useSearchParams } from "react-router-dom";

const \[searchParams\] = useSearchParams();

const category=searchParams.get("category");

## Parameters vs Query String

In short, if there is only index use in the page, use it as parameters,
if there are several data given into the page, use query string.

All the dynamic path and query string available both on BrowserRouter
and HashRouter
