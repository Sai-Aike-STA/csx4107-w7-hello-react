There are typically three package managers for Node JS, they are:

- npm
- yarn
- pnpm

Here are some brief of their characteristics

### summary

- npm = standard & simplest
- Yarn = improved npm, faster
- pnpm = fastest, modern, very efficient

### PNPM

This course will guide you to use "pnpm" since it is the latest and may
be the next standard for software development.

The pnpm does not come with Node JS, you need to install it explicitly
using:

npm install -g pnpm

Yes, you need npm to install pnpm just like you once needed Internet
Explorer to download Google Chrome.

Because:

- npm comes bundled with Node.js
- pnpm does NOT

So we use the default (npm) to install the better one (pnpm)
